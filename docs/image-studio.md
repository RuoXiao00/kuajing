# 图片工作室：从页面到 Coze，再到本地原图

入口是 `src/compoment/tupian/Tupian.jsx`，页面地址 `/tupian`。后端仍使用项目现有的 `python -m backend.run_api`，不需要再启动一个图片服务器。

## 使用与配置

1. 在项目根目录 `.env` 设置 `COZE_API_TOKEN` 和 `COZE_WORKFLOW_ID`。当前工作流 ID 为 `7687948198364037155`，使用中国区 `https://api.coze.cn`。
2. 令牌须能访问该工作流所在空间，并具备文件上传 `uploadFile`、工作流运行 `run` 权限；工作流要发布为 API。环境变量变化后重启后端。
3. 在页面选择生成类型并上传产品图即可生成。**只有产品图必填**；提示词、模特图、背景图全部可选，选择组合类型也不强制补齐可选参考图。每类最多两张、总计最多五张，每张不超过 10 MB。按钮旁会显示缺少产品图、连接状态或任务进行中的说明。
4. 点击“生成 4 张”。对话中显示进度，返回图片会下载到本机后逐张出现。点击图片放大，点击“保存原图”下载。刷新或切换页面不会再次生成。

当前真实验收：2026-09-22，已换用用户新提供的有效令牌，并重新加载后端配置。使用自制水瓶测试参考图完成一次真实文件上传及工作流运行，返回 4 张图片，4 张原图均已下载并通过图片格式校验。验收产物保存在系统临时目录，未写入用户正式图片历史或知识库。旧令牌曾返回 HTTP 401 / `700012006`，该授权问题现已解决。凭据不记录在本文或前端中。

## 代码调用链与字段

`Tupian.jsx` → `POST /api/images/jobs` → `ImageService.submit()` → 后台线程 `run()` → `CozeProvider.generate()` → 文件上传 → 工作流 SSE → 下载原图 → SQLite 状态更新 → 页面轮询显示。

- `backend/tupian/api.py` 负责接收 multipart 表单、校验真实图片、会话隔离、读取进度和下载文件。前端的 blob URL 仅用于本地预览，不发给 Coze。
- `provider.py` 先调用 `/v1/files/upload`，再把 `product_img1` 等参数转成 `'{"file_id":"..."}'` 字符串传给 `/v1/workflow/stream_run`。这与官方 cozepy 示例调用的是同一接口。
- `input` 接收可选提示词并补充生成四张的要求。省略、空字符串或纯空白都允许；留空时仅传数量要求，按产品图和生成类型执行。`need_what` 使用截图里的完整意图句子，不能只传前端选项 ID。生图节点自身也应配置输出四张；不足四张会如实展示并提示，不拿重复图补数。
- 选项严格对应截图七种意图。截图中第五种意图“生成产品和模特和多视图”与流程画布某些节点标题并不一致；代码传意图原文，实际分支依赖 Coze 中意图节点的连线。
- SSE 按空行分事件、按节点拼接 `content`，检查消息序号、结束标志和 `Done`。支持结束节点输出 `data/msg`、JSON 字符串套 JSON、URL 对象或 Markdown 图片；优先读取最后完成的结果节点。没有图片时会提示检查结束节点绑定。
- 不自动用示例里的 `resume_data="hey"` 恢复人工问答：遇到 `Interrupt` 明确说明该流程需要调整，避免向工作流提供假答案。

## 保存、重复提交与失败恢复

默认存档在 `backend/tupian/runtime/`，可以用后端变量 `IMAGE_STORAGE_DIR` 调整。`images.sqlite3` 存任务与历史；每个随机任务目录存参考图和生成原图。目录已加入忽略规则，与知识库数据完全独立，不设自动过期清理。

页面的随机 HttpOnly Cookie 对应本浏览器历史；读取、预览、下载都检查归属。清除 Cookie 或换浏览器后不会自动看到原历史，磁盘原图仍保留。因此重要作品仍建议下载备份。

提交时带 `request_id`，数据库唯一约束防止网络重试重复生图；同一浏览器同时只允许一个生成任务。后端线程不跟随浏览器连接结束而退出。服务停止/断电后，未完成任务在下次启动时标记中断，不自动再次执行可能已计费的工作流。

下载时检查公开 HTTPS 地址、大小、格式和像素，下载完成后原子改名，避免页面读到半张图。成功一张就更新一次任务。部分下载失败时保留成功图片，“重试保存图片”只重试下载，不再调用模型；临时源链接已过期时仍可能无法恢复。

当前界面每次提交是一项独立创作；“复用提示词”只回填提示词和生成类型，不隐式把上一轮生成图当作新参考图。页面内已上传的参考图可继续复用，刷新后需重新选择要用于下一次生成的参考图。
